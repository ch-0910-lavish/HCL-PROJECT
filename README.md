# Music Streaming Trends Analysis

## Project Overview

The Music Streaming Trends Analysis project focuses on analyzing music streaming data using Python, Oracle SQL, PL/SQL, Power BI, and GitHub. The project helps identify top artists, popular genres, yearly streaming trends, and relationships between audio features and popularity.

---

## Domain

Sports and Entertainment

- PL/SQL
- Power BI
- GitHub

## Dataset

Spotify Dataset

Dataset contains:
- Song

- Genre
- Streams
- Popularity
- Year
- Danceability
- Energy
- Valence
- Acousticness
